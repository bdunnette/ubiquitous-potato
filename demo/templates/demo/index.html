Zappa & uv Quick Reference

Useful commands for local management and deploying to AWS Lambda: 

# 1. Install dependencies with uv
uv sync

# 2. Run local migrations
uv run python manage.py migrate

# 3. Start local development server
uv run python manage.py runserver

# 4. Deploy first time to AWS Lambda via Zappa
uv run zappa deploy dev

# 5. Subsequent updates after code changes
uv run zappa update dev

# 6. Execute migrations remotely on AWS Lambda
uv run zappa manage dev migrate

# 7. View CloudWatch logs in real-time
uv run zappa tail dev
